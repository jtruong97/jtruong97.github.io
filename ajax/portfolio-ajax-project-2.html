How to install it

On iPhone, open fully-bookd.com in Safari, tap Share, then Add to Home Screen. It gets an app icon and opens full-screen, just like a downloaded app — the first clip above walks through it.

Want to look around first? The sign-in screen has a Try Demo Account button — no sign-up needed.

One codebase

Built with React Native and Expo so the browser and the installed app share a single codebase and a single Supabase backend — same catalog, same shelves, same streak, whichever one you open. Auth carries across both through OAuth 2.0 and JWT, with row-level security keeping shelves and ratings private by default.
